Hardware

Hardware stack.

Robot arm

SO-ARM100/101 low-cost robotic arm. The follower arm is extended with tactile sensor streams; the leader arm is used for teleoperation and demo collection.

SO-ARM100 on GitHub

Tactile sensor

FlexiTac sensor mounted on a custom gripper. The driver reads tactile frames at 2,000,000 baud and exposes a 12 x 32 tactile map.

FlexiTac usage guide

Custom gripper CAD

Modified gripper designed for integrated tactile sensor mounting. The Moving Jaw holds the FlexiTac sensor pad, and the Wrist Roll replaces the stock SO-ARM100 wrist to accommodate the new jaw geometry and wiring.
