# Media Drop Zones

This repo is set up to publish directly from static files, so video updates are file replacements rather than build steps.

## Suggested layout

- `assets/media/tube/overview.mp4`
- `assets/media/tube/act_tactile.mp4`
- `assets/media/tube/act_baseline.mp4`
- `assets/media/tube/dp_tactile.mp4`
- `assets/media/tube/dp_baseline.mp4`
- `assets/media/tube/pi05_tactile.mp4`
- `assets/media/tube/pi05_baseline.mp4`
- `assets/media/tube/smolvla_tactile.mp4`
- `assets/media/tube/smolvla_baseline.mp4`
- Repeat the same pattern for `pipette/` and `peg/`.

## Where to edit captions and notes

Update `assets/site-data.js` if you want to:

- point a slot at a real video path
- change the task descriptions
- replace the conservative coverage matrix with final metrics
- add public paper, code, or dataset links
